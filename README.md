# Project Description: 
Catch hundreds of different pokemon, from normals, to legendaries and even shinies! Obtain badges and climb the ranks of the best catcher to date!

# Project Purpose: 
This project's purpose is to replicate one of the most favorable parts of the popular Pokémon game franchise. Specifically the catching mechanic. The inspiration came from the iconic "Safari Zones" that most Pokémon games have, allowing the player to catch pokemon with the help of a "bait" (gives more hp, less likely to flee, harder to catch) item and a "rock" (lowers hp, more likely to flee, easier to catch) item, while not actually being able to pin Pokémon against each other in battle. Catch normal's, legendaries, and shinies!

# Project Components: 
This project was made primarily through Python, Tkinter, and helped open the door through Firebase experimenting. The primary goal for this game is to have a working global leaderboard; created at a considerably basic level. After all, I don't expect millions of players to play this game anyway 😅 . This project at the very base level is to showcase the analysis of many different rates, test certain security measures, all while allowing the player to immerse themself in a nostalgic realm. This game is similar to the likes of other fan games.

# How to play:
- Clone the repo locally
- Install dependencies: `pip install -r requirements.txt`
- Run the game: `python pokemon_world.py`
- After playing, sync to the global leaderboard: `python sync_to_firebase.py`
